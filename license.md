## 🔍 How Detection Works

Understanding this helps you use the tool sensibly.

| **Detection layer** | **What it looks for** | **Our approach** |
| --- | --- | --- |
| **Signature scan** | Known cheat file hashes | Build re-signed each patch |
| **Memory scan** | Suspicious read/write patterns | External reads only |
| **Behavioural** | Impossible aim, instant snaps | Smoothing + FOV limits |
| **Screenshot** | Overlay artefacts | Stream-proof mode |
| **Server-side** | Statistical outliers | Legit presets included |

**What this means in practice:**

- The loader runs **outside** the game process, so memory scans see less
- Aim smoothing prevents the "snap" pattern that behavioural detection flags
- Stream-proof mode hides the overlay from capture software
- No tool is undetectable forever — every update is a new race

That is why the pack is updated after each patch. Download the new build
instead of running an old one.
